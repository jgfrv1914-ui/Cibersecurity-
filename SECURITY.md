# Security Policy

This repository is intended for educational use, lab work, authorized testing,
and legitimate security operations in controlled environments.

## Responsible use

- Do not run these tools against any system without explicit authorization.
- Use the network and reconnaissance scripts only in isolated lab setups or on
  environments you own or are legally authorized to assess.
- Keep all testing within the scope of your written permission.
- Do not use this project for unauthorized scanning, exploitation, or malicious
  activity.

## Reporting vulnerabilities

If you identify a vulnerability or issue in the repository itself, please
report it responsibly through a private channel or via the project maintainer's
preferred disclosure process.

Please avoid publicly disclosing a security issue before it has been reviewed and
addressed.

## Scope

This policy applies to the repository content, scripts, and documentation as part
of the cybersecurity portfolio and any related tooling included here.
